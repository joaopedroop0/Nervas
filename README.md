#  Projeto equipe Nervas
## 1. Visão do Produto

> **Para** equipes de engenharia de software e gestores de infraestrutura **que** precisam provisionar recursos de nuvem sem ultrapassar o budget, **o** *CloudCost Manager* **é uma** plataforma interna de governança e autosserviço de nuvem **que** automatiza a solicitação de instâncias e valida os custos em tempo real contra o orçamento departamental. **Diferente de** aprovações manuais por chamados e planilhas descentralizadas, **nosso produto** valida limites orçamentários automaticamente e oferece um fluxo inteligente de triagem e ajuste de recursos para arquitetos de nuvem.
